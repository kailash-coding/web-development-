CSS( cascading style sheets ) is a language used to style an d layout HTML elements on a web page - incliding 
   colors, fonts, spacing, positioning, and responsiveness

*three ways to appy css
  1. inline css - style applied directly on an HTML element
  html 
  copyedit
 <p style="color: red; font-weight:bold:'> this is red and bold, </p>

      * easy for quick tests or one-off styles
      * not reusable; clutters HTML


2.  internal css - style written in a <style> tag inside the HTML <head>
  html
  copyedit
 <!DOCTYPE html>
 <html>
 <head> 
    <style> 
     p{ 
       color: green:
       font-size: 18px;
   }
</style>
</head>
</body>
      <p> this is a green paragraph using internal CSS. </p>
</body>
</html>

     * keeps styles in one plase for a single HTML file
     * not reusable across muitiple pages

3. external CSS - styles are in a separate . css file
HTML file
 <!DOCTYPE html >
<html>
<head>
  <link rel="stylesheet" href="style.css">
</head>
</body>
   <p> this is styled by external CSS, <p/>
</body>
</html>

styles.css file
 p{
   color: purple:
   font-size: 22px:
  }


* best practice for large projects
* reusable, clean, and easy to maintain
* requlres extra file ( but that's a good thing a good hting in real projects)
