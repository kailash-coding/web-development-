specificity decides which css rule wins when multiple rules apply to the same element 

* specificity scire sytem 
           selector type                   score 
       inline styles                     1000
      id selectors                       100
      class/attr/pseudo-class            10
     element/pseudo-element              1
     universal                           0

* quick tips
  =>  id > class > element 
  => inline style beat all ( unless overridden by limportant)
  => avoid using too many ID selectors - classes are more flexible
  => keep specificity low for easier overrides
