 html (hypertext markup language) is the standard language used to create webpages. it structures the content and content tells the browser how to display text, image, links, and other elements


 <!DOCTYPE html>
 <html>
  <head>
   <title>page title </title>
  </head>
 <body> 
  <h1> this is a heading</h1>
  <P> this is a paragraph </p>
 </body>
</html>


 <!DOCTYPE html> : declares the document type
 <html> : root elemment of the html document 
<head> : contains metadata (e.g.,  title , stylrs, scripts)
<title> : title of the document shown in the browser tab)  
 <body> : contains the visible content

EMMBEDDING OTHER MEDIA INTO HTML PAGES
an <iframe> (short for inline frame ) is an HTML tag ised to embed another web page or 
 resoure inside the current HTML document

<iframe src="https://evample.com"width="600" height="400"<>/iframe>
src: URL of the page you want to embed
width and height: dimensions of the oframe in pixels

common attributes
      attribute                    description
     src                   URL of the document to embed
    width, height          size of the iframe 
     title                 accrssible label for screen readers
     allowfullscreen       allows the oframe content to go fullscreen
     loading="lazy"        improves perfomabce by loading on demand
    sandbox                adds security restrictions to the ifeame
   feameborder            controls border visibility (use css instead)
